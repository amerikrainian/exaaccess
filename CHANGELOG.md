# Changelog

## V0.1.0

- First packaged release. The installer finds the Steam install, downloads the newest release, verifies it, installs it over the game folder (backing up anything it replaces), and can later update, repair, or uninstall.
- Speaks the title screen, the control panel (options, controls, key bindings), the desktop (organizer, chat, program launchers), both cutscene players including dialogue choices, the Workhouse, TRASH WORLD NEWS, and ПАСЬЯНС.
- The EXA editor: the task, windows, hosts, links, files, registers, and highway-sign stops; a typing-first code editor with caret narration; run, step, pause, reset, run-to-line; a test log per run; goal popups mirroring the F1 view; scores, leaderboards, and histograms on completion.
